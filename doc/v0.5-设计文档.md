# v0.5 列表设计

项目version仍1，增加可选lists:[{name,items}]，名称规则与变量一致；两类名称在各自命名空间，可同名。lists.js集中项目格式、数量预算、值限制、1起始整数序号与运行时原子操作。state.lists为Map，初始化复制初始项，运行时不写回project；事件与自制调用共用Map。

变量分类新增listAdd/listReplace/listInsert/listDelete/listClear，以及listItem/listLength返回值。列表字段kind:list，使用已有选择器和表达式编辑框；动态序号和值支持嵌套运算。索引无效直接报错，所有检查在写操作之前完成。单项仅primitive，拒绝嵌套数组/对象与非有限数值。上限30列表、每列表1000项、合计5000项。

list-ui.js管理列表声明工具、初始项弹窗和舞台监视。初始项弹窗逐项选择数字/文字/布尔类型，可增删、清空、取消或保存；分页25项，避免巨量编辑DOM。运行监视显示长度，展开后每页25项，可翻页；不以JSON作为用户输入格式。使用textContent，不拼接用户HTML。删除列表保留已有引用，让运行时给出“列表不存在”，可撤销恢复。

主存储升级inspiration-blocks-v5，优先v5/v4/v3/v2/v1，首次保存保留v4原槽与不可覆盖备份；旧回退编辑不自动合并。版本0.5.0，沿用既有授权推送GitHub及大厅资源#7，不修改APK。
