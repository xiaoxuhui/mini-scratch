# 灵感积木：设计文档

版本 0.1.0；状态：实施中；策略：原生 HTML/CSS/ES modules，零运行时依赖。

1. 三栏工作台：积木库、程序区、舞台与角色属性。小屏单列，舞台优先。
2. `src/core.js` 管理数据校验、不可变积木树编辑、示例和异步解释器；不访问 DOM。
3. `src/app.js` 管理界面、拖拽、自动保存和导入导出；`src/style.css` 管理视觉与响应式；SVG 舞台绘制角色与画迹。
4. `scripts/build.mjs` 将源码复制进 dist。`scripts/serve.mjs` 提供本地静态服务。`node --test` 覆盖引擎与数据边界。

项目格式：`{version:1,name,sprite,backdrop,blocks:[{id,type,value?,x?,y?,children?}]}`。只接受已知类型与白名单字段；导入最大 200 KB；ID 去重；嵌套与总数受限。

解释器每步调用渲染回调并等待可取消延时，重复容器也让出事件循环。AbortSignal 同时中止等待与后续执行。执行步数最多 10000，防止深层重复导致长时间占用。

视觉：暖白工作台、紫色导航、分类色积木；原创几何狐狸 SVG 为默认角色。图形由代码生成，无外部素材请求。
