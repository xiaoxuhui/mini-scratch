# v0.3 自定义素材、录音与命名参数

2026-10-16。合并用户连续补充：角色/背景可导入图片并绘制；声音区录入声音并播放；自制积木可自由增删多个命名参数，类型为数字/字符串/布尔；参数按自己的名字拖入，布尔返回值与槽使用左右尖、上下平的六边形。

| 用例 | 验收 |
| --- | --- |
| M1 | 角色和背景各有素材管理，可导入PNG/JPEG/WebP并标准化PNG，自己绘图、橡皮、撤销、保存；选择后舞台实际显示。 |
| M2 | 自定义素材随作品保存、导出/导入、撤销和重载保留；删除被引用素材时回到内置项，不破坏其他素材。 |
| M3 | 声音区可开始/停止麦克风录音，试听、命名、保存、删除；运行播放录音积木，停止结束声音。权限拒绝/不支持/取消/超时可恢复，流轨道全部关闭。 |
| P1 | 自制定义有参数名称和类型，可增删多个；调用显示各个命名参数；数字、字符串、布尔参与移动/文本/条件实际运行，嵌套调用作用域独立。 |
| P2 | 定义内参数名可拖到对应槽，也可点击选择；重命名保持引用，删除参数清理其引用和调用值。原“本次调用的参数”不再作为新版参数入口。 |
| P3 | 检测真假、比较/逻辑及布尔命名参数为六边形；数字和文字使用圆角形；如果/直到布尔槽同样六边形。 |
| C1 | 旧作品与单参数定义可升级；保留旧v2槽与不可覆盖备份，新版独立v3槽，旧版后续编辑不自动合并。 |
| C2 | 媒体大小/格式、表达式深度、参数节点预算、音频时长、循环与调用上限有效；桌面/手机/单文件真实检查、引擎与生命周期测试有证据。 |

实现约束：素材总数据URL预算约2MB，单图标准化到最大960px，绘图角色320×320/背景480×360；音频单段最长30秒，数据随作品内嵌且不上传。参数可自由添加，受既有2000参数节点和作品总大小预算保护，避免宣称真正无限。录音必须用户点击后请求麦克风；旧大厅未开放时提供明确提示及系统音频导入路径，不假装已经录音。
