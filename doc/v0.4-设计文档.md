# v0.4 事件脚本设计

项目version仍1，新可选eventScripts:true表示显式事件语义。events.js纯函数将旧的全部顶层动作按原先执行顺序收进一个whenFlag容器，容器放在最前面，保持旧引擎“先入队顶层脚本，再入队其他绿旗”的顺序；原事件与定义的相对顺序保留。已标记项目不再迁移，因此删除帽子后游离动作不会被下次保存重新包裹。

运行时start({triggerFlag=true})支持只初始化会话而不触发绿旗。显式作品不运行顶层普通动作，旧直接调用接口继续原有隐式行为。应用按键和角色点击匹配已存在事件时，从相应触发启动会话；编辑输入和弹窗不触发快捷键。启动按钮保持绿旗语义，停止结束全部会话与声音。

编辑区根列表内事件/定义添加间距和各自组标识，移除固定帽子，游离动作显示未连接提示。添加事件后将点击目标自动设为该事件内部。事件本身继续现有排序/拖动/删除/撤销模型。显式作品预算301节点，为旧300节点增加一个事件帽留空间；事件容器不占控制嵌套层数，事件/定义仍禁止嵌套，保留旧8层作品边界。

新主槽inspiration-blocks-v4，备份v3且保留原v3；旧v2/v1备份规则保留。类型、素材和具名参数不变。版本0.4.0，对应大厅资源#6，沿用已授权的GitHub和大厅发布，不修改APK。
