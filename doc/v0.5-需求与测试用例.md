# v0.5 变量分类中的列表

2026-10-16。用户要求在变量分类加入列表，以及末尾添加、替换、插入和删除。

| 用例 | 验收 |
| --- | --- |
| L1 | 变量分类同时管理变量和列表，可新建、删除列表，编辑初始项；列表项支持数字、文字和布尔。 |
| L2 | 四种核心积木：添加到末尾、替换第N项、在第N项前插入、删除第N项；补充清空、读取第N项和列表长度供计算使用。 |
| L3 | 序号从1开始且为整数；插入可用长度+1追加到末尾，其他越界/无效序号明确报错且不改数据。空列表可追加/在1插入。 |
| L4 | 不同事件和自制积木共享当前列表，取值可用于运算/动作/参数；运行不会改写项目初始项，新会话恢复初始项。 |
| L5 | 列表随保存、导入/导出模型往返、撤销和重载保留；独立v5槽保留v4/v3/v2/v1原槽及备份，旧无列表作品兼容。 |
| L6 | 每个列表最多1000项、最多30个列表、所有列表合计5000项；单项文字最多80字符。坏格式、重复名、无效值和超限拒绝，不破坏已有项目。 |
| L7 | 桌面/手机检查新建、初始项编辑、四种操作、读值、运行监视、撤销和刷新，构建/测试/GitHub/大厅完整交付。 |
