# v0.3 设计

新模块：assets.js校验与素材操作、asset-editor.js素材/画布界面、recorder.js麦克风生命周期；procedures.js管理可变参数签名与引用。继续原生模块，构建器生成单文件。

项目version仍1，增加可选assets（sprites/backdrops/sounds），自定义选择ID使用asset-前缀。图像只保留PNG数据URL，音频接受受限MIME与base64。新版主存储键v3，优先v3→v2→v1，首次写新版保留原槽和备份；存档保护测试更新为三代。项目导入最大4MB，素材预算约2MB，保存失败保留当前作品并可导出。

新define.parameters为{id,name,type}数组，call.arguments为{parameterId,value}数组；parameter返回值含definitionId/parameterId，按稳定ID关联，名称重命名不破坏引用。原parameter/value与argument结构继续可运行并在编辑新签名时迁移。参数删除替换其返回值为类型默认值并移除调用值，避免隐形悬空引用。调用按声明类型转换，局部Map作用域。

布尔类型元数据驱动六边形类；字面真假选择器、表达式、命名参数、插槽和预览同步。参数拖拽保留原application/x-block载荷并扩展表达式payload，点击路径用于触摸。素材图片通过DOM/SVG image绘制，不将用户SVG/HTML插入innerHTML。录音启动token保护异步权限返回与取消，任何退出/隐藏/失败都停止轨道，试听和脚本共享可取消AudioContext。
