# v0.2 设计

状态：实施中。原生模块，零第三方运行依赖。

- blocks.js：分类、积木类型与字段描述；project.js：校验、树编辑、向后兼容、示例；expressions.js：纯返回值运算；runtime.js：可取消协作解释器；core.js 保留旧导出入口。
- app.js 保留项目协调，editor.js 管理积木与返回值编辑，audio.js 管理 Web Audio；舞台继续使用 SVG。模块构建器生成可离线打开的单文件，源目录逐文件核对。
- 旧根程序仍是隐式绿旗；事件帽子和自制定义是根级容器。if 有 children/otherwise 两分支，所有树操作遍历两分支。
- 参数可为字面量或 `{type:<返回值类型>, ...字段}`；嵌套由字段描述驱动，不执行用户 JavaScript。返回值编辑弹窗允许选择类型、编辑输入及嵌套；拖拽返回值到参数也可替换。
- 变量声明数组 `{name,value}` 可选；旧作品未有字段时不凭空写入。运行值使用 Map，声明值和运行值分离。自制 define 的 name 与 parameter、children 在程序树中，call 的 name/value 提供局部实参。
- runtime 工厂共享舞台/变量/感知，脚本有各自实参上下文；AbortController 停止所有任务与音频，运行中锁编辑。含按键/点击/广播帽子的项目保留会话等待事件，否则任务耗尽自动结束。
- 保持主存储键 inspiration-blocks-v1；首次写入扩展作品前将最后一份仅含旧积木的存档留在 inspiration-blocks-v1-legacy-backup，绝不覆盖已有备份。更新大厅资源时明确0.1旧阅读器不认识新类型，避免宣称可双向编辑兼容。

验证：纯引擎和表达式测试使用注入的时钟/随机/感知/声音回调；旧版17项基线保留。浏览器用实际操作验证参数保存、嵌套、键盘和角色点击及停止清理。
