# 灵感积木：需求与测试用例

版本：0.1.0；状态：已实现，文件导入导出的浏览器端验收受限；日期：2026-10-15。

面向初学者的中文 Scratch 简化版，浏览器本地使用，无账户与服务端。

| 编号 | 行为与验收 |
| --- | --- |
| U01 | 点击或拖拽积木加入程序；可编辑参数、上下调整、删除；重复积木支持嵌套。 |
| U02 | 绿旗按顺序执行，运行中高亮当前积木；停止立即取消后续动作，重复运行不叠加。 |
| U03 | 支持移动、转向、前往坐标、说话、等待、重复、画笔开关、清除画迹。 |
| U04 | 舞台 480×360，中心为 (0,0)，向右为 x 正向，向上为 y 正向；方向 0 向右、正转顺时针；角色中心限制在舞台内。 |
| U05 | 重复次数取整并限制 0–100，嵌套最多 8 层，积木最多 300 块；数值与导入均校验，文字仅作文本渲染。 |
| U06 | 三个示例可载入；更换示例会替换当前程序；可新建空项目。 |
| U07 | 自动保存程序、角色与背景；刷新恢复；JSON 导出导入；损坏数据提示并保留当前项目。 |
| U08 | 三种角色与三种背景可选；复位回中心并清除轨迹。 |
| U09 | 桌面与手机可操作；点击添加与上下按钮提供触摸和键盘替代路径。循环底部按钮可选择点击添加的位置。 |

运行使用快照，运行时编辑区锁定；执行开始回到中心并清除画迹，结束保留结果。积木树的顺序就是执行顺序，绿旗为固定入口。
