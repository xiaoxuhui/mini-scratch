# v0.4 可独立编辑的事件脚本

2026-10-16，用户要求事件任务与固定主程序分开，主程序可删除，因为启动不只绿旗一种。

| 用例 | 验收 |
| --- | --- |
| E1 | 删除固定“主程序·绿旗启动”装饰。绿旗、按键、角色点击、广播、自制定义各自独立成组，可排序和删除。 |
| E2 | 点击添加事件后，动作默认进入该事件；删除整组包含其动作，可撤销。无事件连接的顶层动作明确提示且不自动运行。 |
| E3 | 按键/角色点击可直接启动相应事件，不要求先点绿旗，也不顺带触发绿旗；绿旗按钮触发绿旗脚本并启用会话，停止仍可结束。 |
| E4 | 旧作品顶层动作迁移到显式可删除绿旗组，原动作顺序/ID/其他事件/定义保留；再次迁移不重复包裹。 |
| E5 | 新版独立v4存档，依次读v4/v3/v2/v1并保留原槽及不可覆盖备份。旧直接execute接口兼容；新显式事件作品不会偷偷运行游离动作。 |
| E6 | 桌面/手机验证添加、删除、撤销、按键/点击独立启动与绿旗隔离；自动化、构建、推送与大厅资源保持可追溯。 |
