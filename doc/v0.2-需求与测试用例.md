# v0.2 九类积木需求与测试用例

2026-10-15；状态：已实现，验证范围见v0.2测试报告。用户要求增加运动、外观、声音、事件、控制、检测、运算、变量和自制积木。

简易版继续采用单角色，不承诺 .sb3 或完整 Scratch 兼容，保留画笔扩展。所有分类必须有可执行行为，不能只是导航占位。

| 编号 | 验收 |
| --- | --- |
| V01 | 九类与画笔可切换，桌面/手机可添加积木，嵌套块可选添加位置。 |
| V02 | 运动包含移动、转向、坐标、滑行和碰边反弹；外观包含说/想、显隐、大小、造型与背景。 |
| V03 | 音符、音量与停止声音实际调用 Web Audio；停止/复位取消音符和等待，不需要外部音频。 |
| V04 | 绿旗、按键、角色点击、广播事件按所选条件触发；停止后没有残留事件执行。 |
| V05 | 循环、一直重复、如果/否则、重复直到、停止脚本可使用布尔表达式；空循环也可取消并受步数限制。 |
| V06 | 检测返回坐标、鼠标位置、按键/鼠标状态、碰边、计时器等；参数输入支持返回值积木和嵌套表达式。 |
| V07 | 四则、随机、比较、逻辑、字符串及取整运算不使用 eval；除零给出明确错误，随机可注入测试。 |
| V08 | 新建/删除命名变量、设为/增加、读取和舞台监视器；声明值随项目保存，运行从声明初值开始。 |
| V09 | 命名自制积木定义可含一个参数，调用时参数独立，支持嵌套调用；缺失定义/递归超限明确提示。 |
| V10 | v1 作品无损载入运行；扩展字段仍用 version=1；新版独立使用 v2 存档槽，首次读取 v1 后保留原槽和不可覆盖备份。旧0.1不认识新类型，旧版后续编辑不合并到新版。 |
| V11 | 导入限制、表达式深度、节点总数、变量数、并发任务和调用深度受限；项目文本只作文本渲染。 |
| V12 | 桌面与390px手机实际添加、表达式编辑、事件、变量、自制积木、停止、保存重载检查有记录；旧方形/花朵回归通过。 |

规则：方向沿用0向右、顺时针为正；运行变量彼此共享，事件任务协作调度；同一事件未结束时忽略重复触发，最多32个同时运行脚本。广播不等待监听脚本，防止互相等待死锁。自制参数局部、变量全局，调用最多32层，总执行10000步。声明变量最多30个。始终运行的事件/循环需要用户按停止退出。
